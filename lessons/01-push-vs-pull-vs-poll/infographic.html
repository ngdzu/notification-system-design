Push vs. Pull vs. Poll

three ways to move a message · and the trade-off that rules the whole course

① Push — server calls you

latency ≈ 0s cost: connection per client, 24/7

② Pull — you ask the server

survives disconnects latency ≤ poll interval

③ Hybrid — what real systems run

push when connected pull after reconnect / on app-open

Same event, two arrival times

The core tension — every lesson picks a point on this beam

latency = how fast one message lands throughput = how many msgs/sec total

Why scale bites: fan-out — 1 event → N notifications
